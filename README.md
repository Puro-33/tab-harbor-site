# Tab Harbor 개인정보 안내

Chrome 탭 보관함의 개인정보처리방침과 백업 안내를 제공하는 공개용 사이트 소스입니다. 사용자의 보관 URL이나 DB를 읽지 않으며, 저장·업로드 기능이 없습니다.

공식 Sites 템플릿과 Vinext를 사용합니다. Node.js 22.13 이상에서 npm install, npm run dev, npm run build 순서로 개발합니다. Windows PowerShell에서는 npm.cmd를 사용할 수 있습니다.

배포 프로젝트는 .openai/hosting.json의 project_id로 식별합니다. 소스 인증 정보나 사용자 개인정보는 이 저장소에 저장하지 않습니다.
